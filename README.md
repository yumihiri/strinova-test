# strinova-test

玉対戦ゲーム(要件定義書セクション10「1. 土台」〜「5. スキル・必殺技の導入」の実装)。

画面遷移: **キャラクター選択 → マップ選択 → バトル(→もどる/リセット)**。
キャラクター選択画面で `BallBattle/Content/Characters/characters.json` の23キャラから対戦させる2体をクリックで選び、
マップ選択画面でフィールド(現状は正方形1種類のみ)を選んでバトル開始。バトル画面はCPU対CPUの自動対戦を観戦するのみで、
プレイヤーが操作できるのは画面遷移のボタン(もどる/つぎへ/バトル開始/リセット)のみ。

正方形フィールド内で2つの玉が壁に当たるまで直進し、当たったら新しいランダム方向へ進む。接触すると衝突ダメージ・
ノックバックが発生する。HPバー・勝敗判定・「もどる」(キャラ選択に戻る)・「リセット」(同じ組み合わせで再戦)ボタンを表示。

## スキル・必殺技(セクション10-5)

- **スキル(ダッシュ突進・クールダウン制)**: 一定間隔(5秒)で自動発動。短時間、通常の2.5倍速で直進する。
  ダッシュ中に接触すると相手に追加ダメージ+短時間スタンを与える(ダッシュ側は無傷、一方向の効果)。命中すると
  ダッシュはそこで終わる
- **必殺技(必殺技ゲージ・時間経過制)**: ダメージ量ではなく経過時間でゲージが蓄積し、60秒で満タンになると
  自動発動する(キャラごとの強い/弱いは、今後このチャージ時間の差で表現する想定。現状は全キャラ共通の60秒)。
  発動中は通常の3倍速で2秒間直進し、命中すると大ダメージ+長めのスタンを与える。発動後ゲージは0にリセット
- HPバーの下に紫(スキルクールダウン)・金(必殺技ゲージ)のミニバーを表示。発動可能/発動中は白枠で強調される
- 玉の見た目: 突進中は進行方向に残像とグローの強調(必殺技は金色)、スタン中は頭上で3つの星が回転する
- スキル・必殺技の効果はキャラ問わず共通の1種類のみ(ダッシュ突進)。仕様書の「今回はスキルの具体的な種類を
  絞って導入する」方針に沿ったもので、キャラごとに異なるスキルを持たせるのは次段階以降

## バランス調整

ステータス(HP・移動速度)は未調整のため現状は全キャラ共通値。1試合30秒〜1分半程度を目安に、玉の半径・速度・
ダメージ量、スキル/必殺技の数値をヘッドレスシミュレーション(1000試合)で「試合時間 平均約58秒(中央値約59秒)
/90%タイルで84秒、必殺技(60秒チャージ)が発動できる試合は約5割」になるよう調整済み(`GameConfig.cs`参照)。
必殺技の突進時間(`UltimateDurationFrames`)は、短すぎると自然な衝突間隔に対してほぼ命中しないことがシミュ
レーションで判明したため、意図的に長め(2秒)にしてある。

なお、現状は全キャラHP・与ダメージが同一のため、通常衝突の対称ダメージだけを見ると引き分けになりやすい
(スキル・必殺技のダメージは片方だけに入るため、実際には発動タイミングの運次第で決着がつくこともある)。
キャラごとのステータスに差をつける段階(セクション10-6以降)で、この偏りはさらに解消される想定。

ウィンドウ・フィールドは将来のWeb公開を見据えて一回り大きくしてある(900×1060、フィールド760×760)。
玉の半径・移動速度・ダメージ計算の速度依存係数も同じ倍率で追従させており、旧サイズ(640×760)で検証済みだった
衝突頻度・試合時間の統計的な傾向は変えていない。

C# / MonoGame で実装している(`BallBattle/`)。文字描画は [FontStashSharp](https://github.com/FontStashSharp/FontStashSharp)
を使い、同梱のIPAゴシックフォント(`Content/Fonts/ipag.ttf`、IPAフォントライセンスv1.0で再配布可)で
日本語を含めて描画している。コンテンツパイプライン(SpriteFont/MGCB)は不要で、実行時にTTFを直接読み込む方式。

キャラアイコンは、まだキャラごとの個別画像が用意されていないため、全キャラ共通で1枚の画像
(`Content/Icons/IMG_2210.png`)を表示している。`characters.json` の `icon` に個別画像パスを指定すれば
そのキャラだけ差し替わり、指定した画像が読み込めない・見つからない場合は自動で`Content/Icons/placeholder.png`
(グレーの人物シルエット)にフォールバックする。

UIはダークテーマ・角丸パネル・ドロップシャドウ・玉のグロー等を使った見た目に調整済み(色や角丸の半径は
すべて`GameConfig.cs`にまとめてある)。角丸矩形・輪郭線・アイコンの角丸クリップはコンテンツパイプラインや
外部ライブラリを使わず、1x1の白ピクセルテクスチャをスケーリング描画する自前のラスタライズ処理(`Game1.cs`の
`FillRoundedRect`/`DrawRoundedRectBorder`等)で実現している。

## 実行方法

.NET 8 SDK が必要。

```bash
cd BallBattle
dotnet run
```

VS Codeの場合は `BallBattle` フォルダを開き、ターミナルで上記コマンドを実行すればよい。
